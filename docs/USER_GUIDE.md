# App 发布中枢 · 用户操作说明

> 适用对象：所有使用本平台查询 / 发布 App 的同事
> 看板地址：办公网内 `http://<部署机IP>:8090`（以实际部署为准，本机访问 `http://127.0.0.1:8090`）
> 配套文档：`WEB_GUIDE.md`（管理员视角：部署、飞书接入、HTTP API），本文是**纯使用者视角**

---

## 一、平台能做什么

| 能力 | 说明 |
| --- | --- |
| **一键多平台发布** | 上传一次安装包，并行发布到 华为 / OPPO / vivo / 小米 / 荣耀 / 腾讯应用宝 / Google Play（共 7 个平台） |
| **审核状态查询** | 一键查询各平台：已上架版本、审核状态、草稿版本 |
| **状态分享图** | 一键生成竖版状态图，可直接粘贴到微信 / 钉钉 / 飞书 |
| **定时上线** | 小米 / OPPO / vivo / 荣耀 / 华为 / 腾讯应用宝支持定时发布 |
| **多应用并行发布** | 不同 App 可同时发版互不干扰，各有独立进度 |
| **飞书群通知** | 发布结束自动推结果卡片到群（全部成功 / 部分失败 / 全部失败都发） |
| **飞书机器人查询** | 群里 @机器人「查询 应用名」，秒回状态分享图 |
| **账号权限** | 按应用授权，各负责人只能看 / 发自己的 App |
| **发布历史** | 每次发布的完整记录永久保留，可追溯 |

Apple（苹果 App Store）目前**仅用于查询线上版本**，不参与发布。

## 二、账号与登录

### 1. 三种角色

| 角色 | 能做什么 |
| --- | --- |
| **owner**（管理员） | 全部应用 + 发布 + 用户管理（增删账号、分配权限） |
| **publisher**（发布员） | 查看与发布**被授权**的应用、上传安装包、停止任务、查询 |
| **viewer**（只读） | 查看**被授权**的应用、查询状态、下载 APK；不能发布 |

- 账号由 owner 在「用户管理」里创建；每个账号可指定能看哪些 App（不指定 = 全部）
- 未授权的应用**完全不可见**（侧栏、任务、历史里都不出现）

### 2. 登录

1. 浏览器打开看板地址，输入账号密码
2. 登录后右上角显示你的账号、角色与授权应用数量
3. 会话有效期 7 天（`session_days` 可调），期间访问自动续期；改密码 / 权限变更后会立即退出需重新登录

### 3. 修改自己的密码（自助）

1. 右上角点 **「我的账号」**（owner 显示的是「用户管理」）
2. 只能看到自己那一行，点 **「修改密码」**
3. 输入新密码（至少 6 位）→ 保存 → 自动退出，用新密码重新登录

> 权限、角色、应用授权的调整只能由 owner 操作；接口层也做了限制，非 owner 提交角色/授权修改会被直接拒绝并记安全告警。

## 四、发布一个 App（标准流程）

### 第 1 步：选应用
左侧点击目标 App，右侧加载应用信息（包名等）。

### 第 2 步：上传安装包
「构建产物」卡片点 **「选择…」**：

- 国内 6 个平台用 **`.apk`**；Google Play 用 **`.aab`**（可同时上传两种）
- 上传后系统**自动解析**版本名、版本号、包名并回填发布表单——不要手填，核对即可
- 包名与应用不匹配会直接报错

### 第 3 步：填写发布信息
在「发布」卡片确认：

1. **勾选平台**：可多选；有「全部」一键勾选（Apple 不参与发布）
2. **更新说明**：必填，写本次更新内容（商店页面与审核会展示）
3. **定时上线**（可选）：选时间则审核通过后到点自动上架；**留空 = 审核通过后立即上架**
   - 支持：小米 / OPPO / vivo / 荣耀 / 华为 / 腾讯应用宝
   - **应用宝限制**：定时时间必须在提审 6 小时后、30 天内，否则会被拦截
4. **Google 专属**（勾选了 Google 时）：
   - 发布方式：**分阶段发布**（先百万分之一灰度，审核通过后需在看板点「全量发布」）或 **全量发布**（审核通过自动 100% 上线）
   - 可勾选 **「Google 自动送审」**；不勾则只存草稿，需自己去 Play Console 送审

### 第 4 步：点「发布」
- 任务后台异步执行，**不需要停在页面等**
- 勾选的平台**并行**上传与提审，日志区实时滚动每个平台的进度
- 发布中可以切到其他应用做别的事，切回来**自动恢复**进度

### 第 5 步：看结果
- 日志区显示每个平台提审成功 / 失败明细
- 任务结束**飞书群自动收到结果卡片**（含成功平台、失败明细、状态分享图），不需要再在群里手动同步
- 失败的平台写明原因，可只勾选失败的平台补发一次

## 五、查询状态

1. 选中应用，点 **「查询状态」** / **「查询全部平台」**
2. 「平台状态」显示每个平台的：**已上架版本、审核状态、草稿版本**
3. **分享图**：点「分享」生成竖版状态图并复制到剪贴板，直接粘贴到聊天工具
4. 也可以在飞书群 **@机器人 「查询 应用名」**（应用名支持中文 / 英文 / 包名，支持模糊与错别字容错）

查询是并发的，总耗时约等于最慢的平台。苹果商店版本有 5 分钟缓存，刚上架的新版本可能稍后才能查到。

## 六、发布任务管理

| 操作 | 说明 |
| --- | --- |
| **停止任务** | 日志区「停止」按钮，点击后未完成的平台立即中断（手动停止不发飞书通知） |
| **重复发布拦截** | 同一个 App 已有任务在跑时，再次发布会提示现有任务详情并拦下 |
| **部分失败** | 按平台独立执行：一个平台失败不影响其他平台；结束后可只补发失败的 |
| **发布历史** | 底部可查每次发布完整记录（时间、操作人、平台、成败明细），永久保留 |
| **多应用并行** | A 在发布时切到 B 照常发，互不影响；你不在该应用页面时它发完了，日志区会补一条「[应用名] 刚才的发布已结束」 |

> 上传有全局并发上限（防止多个 200MB 大包同时上传把网络打满）：极端情况下多任务同时传大包会排队，属正常现象。

## 七、飞书机器人

群内 @机器人 支持的指令：

| 指令 | 作用 |
| --- | --- |
| `@机器人 查询 <应用名>` | 回复该应用各平台状态分享图（会 @ 回提问的人） |
| `@机器人 查询 全部` | 逐个应用查询（较慢，每个查完即回图） |
| `@机器人 绑定通知群` | 把当前群设为发布通知群（仅管理员用） |
| `@机器人 解绑通知群` | 取消通知群绑定 |
| `@机器人`（或「帮助」） | 回复用法说明 + 可查询应用列表 |

私聊机器人同样可用（不用 @）。口语化说法也能识别，如「凯迪仕版本多少」「帮我查一下 homeaccess」。

发布完成通知卡片内容：结果（✅ 全部成功 / ⚠️ 部分失败 / ❌ 全部失败）+ 应用与版本 + **成功平台（N）** + 失败明细 + 状态分享图 + 「打开看板」按钮。dry-run 演练、手动停止、仅存草稿默认不发通知。

## 八、常见问题（FAQ）

**Q1：发布到一半失败怎么办？**
看日志区失败明细。网络类错误（连接超时 / 重置）直接重新发布即可，平台已内置自动重试（荣耀/应用宝整包重传 3 次、荣耀 token 重试 3 次）；补发时只勾失败的平台。

**Q2：OPPO 显示发布成功但后台没有审核记录？**
平台已内置提交自检：OPPO 后台未受理时自动回查最多 180 秒，仍无审核任务会**直接判失败**，不会出现假成功。遇到就重新发布一次。

**Q3：Google Play 状态是「待发布」是什么意思？**
分阶段发布（百万分之一灰度）阶段统称「待发布」——Google API 无法区分「还在审核」和「已通过在灰度」。需要正式上线时在看板点 **「全量发布」**。被拒只能到 Play Console 人工查看。

**Q4：Google Play 发什么格式的包？**
必须 **AAB**（`.aab`），APK 不被接受。同一应用可同时传 APK（发国内）+ AAB（发 Google）。

**Q5：华为「待发布」怎么让它提前上架？**
华为定时版本在「待发布」状态可点 **「立即上线」**（owner / publisher 均可）；其他平台官方没有提供立即上架 API。

**Q6：小米一直「审核中」但其实被拒了？**
小米接口不返回审核状态与拒绝信息，看板用版本号推断（线上 < 提审 = 审核中）。被拒会持续显示「审核中」，需到小米开发者后台核实。

**Q7：看不到某个应用 / 没有发布按钮？**
账号未被授权该应用，或角色是只读。联系 owner 在「用户管理」里调整。

**Q8：提示「只能修改自己的密码 / 角色与应用授权只能由 owner 修改」？**
接口的正常防护。权限相关变更都找 owner。

## 九、安全须知（务必遵守）

1. **账号密码不外传**；发现异常登录立即改密并通知 owner
2. **发布是真实操作**：会真实提审各平台并消耗配额，不确定时先找 owner 做演练（dry-run，不真实提交）
3. 所有登录与操作都有**审计记录**；越权尝试会触发安全告警通知 owner
4. 平台各商店凭证由管理员统一保管，**任何凭证不要通过聊天工具传输**
5. 看板仅供办公网内访问，**不要做端口映射暴露到公网**；外网需要请走 VPN
6. 最终上架结果**以各平台开发者后台为准**

---

## 十、遇到问题找谁

- **账号 / 权限 / 看板访问**：联系 owner（管理员）
- **发布失败排查**：把日志区失败明细截图发给管理员
- **审核被拒 / 平台侧异常**：到对应开发者后台核实（Google → Play Console，小米 → 小米开发者后台）
